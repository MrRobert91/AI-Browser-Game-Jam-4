# La Última Observación — página de itch.io

El mundo no existe hasta que lo miras.

Walking game 3D de diez minutos. Camina, sostén la mirada para fijar posibilidades, encuentra Semillas que amplían el vocabulario del planeta y deja un retrato de tu atención.

## Controles

- WASD o flechas: movimiento.
- Ratón: mirar (Pointer Lock tras calibrar).
- Shift: correr. Espacio: saltar.
- Escape: pausa y opciones.
- R mantenida dos segundos desde pausa: reiniciar.

## Accesibilidad

Sensibilidad, invertir Y, cabeceo, destellos reducidos, alto contraste, subtítulos, calidad y volúmenes separados.

Build gratuita, autosuficiente y offline después de cargar sus archivos. Escritorio WebGL2; Chrome, Edge y Firefox actuales. No hay telemetría ni generación remota.
